# brixt_r's combat kit

![Items preview](https://cdn.modrinth.com/data/cached_images/defabede97519a9e3891098a08244ba0860698e0_0.webp)

This mod adds items to 3 unique categories:

## 1. Food :
  2. Shawarma - An item that when eaten, gives its user a temporary jump boost
  3. Asguardian Mead - A drink that is a blend of commonly used potions

## 2. Weaponry : 
   1. Karambit - A short-ranged blade that gives the user a speed boost
   2. Stormbreaker - A battle-axe with a cool right-click ability
   3. Mjolnir - A battle-hammer that also allows the user to propel themselves forward

## 3. Armor : 
   1. Winged Battle Helmet - Gives the user Resistance I when it is worn during the rain
   2. Breeches - Gives the user the ability to double-jump

These items allow for a new style of PvP, what I'd like to call **Warlord PvP**

Its also fun to add this mod to a server and try to become the most powerful. I've added items that can be obtained easily but also quite difficult to obtain so that there is a challenge every player needs to undergo to gain the power of the weapons they wield.

> This mod is inspired by Thor, from Avengers
